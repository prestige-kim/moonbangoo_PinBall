# 맵별 장애물 이미지 보강

2026-10-15. 이미지 생성 도구(image_gen)로 맵별 재질 PNG 4종을 제작하고 장애물에 적용했다. **로컬 변경이며 push·병합·배포하지 않았다.**

## 맵별 보강

| 맵 | 생성 재질 | 적용 대상 |
|---|---|---|
| 연못 정원 | 대나무·옥빛 물결 조각·황동 테두리 | 핀·범퍼·경사로·회전 막대 |
| 바람 도서관 | 호두나무·녹색 가죽·황동 장식 | 이동 서가·책 수레·책받침·피날레 |
| 빗살 협곡 | 층리 사암·구리 테두리·광물 균열 | 경사로·빗살·핀·로컬 v7 바위턱 |
| 태엽 공장 | 두꺼운 황동 면·청록 에나멜·기계 홈 | 드럼 날개·링·분기·패드·이송 패드·보석 받침 |

기존 흰 속면의 가는 선 표현을 입체 테두리와 불투명 재질로 채웠다. 이미지는 실제 충돌체의 캡슐·원 모양 안에 클리핑하며 실제 이동·회전 위치를 따른다. 생성 PNG의 넓은 투명 여백을 source rectangle로 제외해 그림 자체가 몸체 높이를 채우도록 했다. PNG 원본의 투명도는 보존했다.

태엽 공장 첫 시안은 중앙 남색이 배경에 묻혔다. 이미지 생성 도구로 중앙 면을 밝고 꽉 찬 황동으로 편집한 v2를 최종 적용했다. 첫 시안도 비교용으로 남겼다. 맵당 이미지는 한 번 로딩해 재사용하며 로딩 중·실패 시 기존 도형을 사용한다. GitHub Pages 하위 경로를 포함한 에셋 URL을 검사했다.

- 공통 물리·맵 지형·장애물 크기·속도·위치·맵 버전·출발 기록 서명은 변경하지 않았다. 로컬 버전은 연못 정원2·도서관9·협곡7·태엽 공장5다. 따라서 대규모 시간·극단 설정 검사를 반복하지 않았다.
- 기존 로컬 협곡 v7의 시간 균형 실패는 그대로다. 이번 이미지 보강은 그 지형의 시간 문제를 해결한 작업이 아니다. 해당 원자료와 판단은 [협곡 시안 보고서](../canyon-ledges/REPORT.md)에 보존했다.

## 기준과 종료 상태

실제 배포 기준 및 원격 main은 a41acdf이며, 작업 시작 때 서비스53개 파일 해시가 일치했다. [배포 기준 기록](../final-review/deployment/service-source.json)을 재확인했고 새 조회 결과도 별도 기록했다. 작업 분기는 배포·원격 기준 이력을 포함한다. 시작 HEAD는 5fe13bc다. 이미지 보강에 필요한 파일만 로컬 커밋에 포함하고 기존 AGENTS.md·RELEASE_MANAGEMENT.md·fairness 변경은 건드리지 않는다.

서비스는 기존 배포 상태이며 이미지 보강과 협곡 v7은 아직 반영하지 않았다. 이번 검증은 네 맵 대표 흐름과 시각 표현의 범위이며 모든 기기·시드·FPS를 보장하지 않는다.
