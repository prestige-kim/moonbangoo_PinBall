## 의도한 변경

그룹 이름을 표준 HTML 텍스트 입력창에 입력하고, 색상·수량·그룹 추가/삭제·저장·재현을 지원한다. 기존 설정의 이름과 순서를 유지하며, JSON `groupVersion:1`로 구분해 쉼표·별표가 있는 이름도 입력할 수 있다. 한글 조합 중 DOM 입력창을 교체하지 않고, 터치 키보드로 가용 화면이 작아지면 설정창을 줄인다. [이름 입력 구현 기록](../group-names/REPORT.md)의 당시 로컬 상태를 이번 배포 완료 상태로 소급 변경하지 않는다.

발사 출구 폭을 `.18S`에서 `.24S`로 33% 넓혔다. 표시·물리 벽 끝·통과 판정이 같은 geometry를 사용한다. 안쪽 `.10S` 깊이, 안쪽 폭을 `.04S` 추가 확장한 깔때기를 표시하며, 공을 잡고 내부에서 출구 방향으로 `.025S` 이상 이동해 이 구역에 도착하면 **놓으면 발사!**를 표시한다. 이 수치는 속도 조건이 아니라 단순 터치/미세 흔들림을 거르는 최소 바깥 방향 이동량이다.

구역 안에서 놓으면 발사하며, 선을 넘어 미는 기존 즉시 발사도 유지한다. 구역 밖으로 돌아오면 놓기 발사가 해제된다. 닫힌 벽 바깥에서 구역으로 건너오는 단일 이동, 취소·다중 접촉·blur·resize, 정지한 탭은 오발사하지 않는다. 시각 피드백은 입력 상태를 소비하거나 RNG·출발 슬롯을 변경하지 않는다. 기존 `HandFlight`의 정지 입력에서도 보장되는 기본 추진력과 실제 마지막 표시 위치에서 이어지는 비행을 그대로 사용한다.

넓어진 실제 출구는 경기 전 셔플 벽의 열린 범위를 의도적으로 바꾼다. 중앙 드래그의 기존 경계 검사 tick 13은 tick 12로 바뀌므로 이유와 기대값을 명시해 갱신했다. 구형 해시를 덮지 않고, `preserved-main-sources.json`에 이 두 파일의 별도 `intentionalRuntimeChanges`·변경 이유·기준 SHA·정확한 새 해시·대체 검사 경로를 추가했다. 다른 보호 파일의 기준을 완화하지 않았다.

경기 물리·맵 버전·시드 스트림·상단 출발점 배정·출발 기록 v2 서명과 복원 조건은 그대로다. 이전 기록을 복원할 때 새로운 셔플 구역을 다시 거치지 않고 저장된 실제 출발점을 복원하므로 같은 실행 환경에서 이전 결과를 유지한다.
