# 배포 판정: 배포 불가

2차 검증 진행 중입니다. R02는 범위 밖 기능이라 철회했고 R11은 경로 제거로 해당 없음입니다. 수정 전 마우스·터치 출발 프로토콜에서 참가자 편향을 확인했습니다. 후보 선택·미사용 holdout·위험 모서리 측정과 최종 재검증이 끝날 때까지 배포를 승인하지 않습니다. 작업 브랜치는 `release-check/fairness-fix`; push·main 변경·배포는 없습니다.

## 1차 감사 기록 (dfeb7de 시점, 역사 자료)

아래의 1차 판단·줄 번호·R02/R10~R12 상태는 당시 범위와 결과를 보존합니다. 현재 상태는 문서 끝의 2차 섹션을 적용합니다.

## 정적 점검 A–F

### A. 난수와 공정성

- 경기 RNG는 `P.seedRandom`(js/physics.js:9)을 사용합니다. spawn `seed+'|launch'`(112), 공별 rescue `seed+'|rescue|'+id`(167), 경기 skills(491), Chamber/js/cinematic.js:217과 셔플은 각자 파생 시드 스트림입니다. **단일 스트림은 아니지만** 시드로 결정됩니다. `sort(()=>Math.random()-.5)`는 없습니다. 실제 Fisher–Yates는 physics 141–150 및 cinematic 29입니다.
- `Date.now/Math.random`은 main 203의 새 시드 생성 crypto 미지원 폴백, effects 16 시각 입자, audio 104 소음에 사용합니다. 이미 생성한 시드의 경기 물리에는 직접 사용하지 않습니다. `performance.now`는 손 입력·표시·음성 시간입니다. 손동작은 실제 출발에 영향을 주므로 시드 하나만으로 손 출발까지 결정된다는 주장은 부정확합니다.
- 입력 순서는 pair solver 처리 순서(physics 419), skills의 공유 RNG 소비 순서(491), 정확히 같은 도착 시간의 입력 순서 타이브레이커(591)에 남습니다. 동률 규칙은 결정적이며 원본 규칙을 유지했습니다. 슬롯/그룹/ID별 통계는 수치 부록에 기재하며, 유의하지 않다는 결과가 완전한 균등의 증명은 아닙니다.

### B. 결정론

- 물리 step은 전달 dt를 사용하지 않고 tick×1/120을 사용합니다(physics 515). 실제 main의 accumulator와 48스텝 제한은 main 333–336이며 렌더 dt는 0.12초로 제한합니다(378). 접전 slow-motion은 물리 스텝 수만 늦춥니다. 표시 경과 시간은 벽시계 시간이 아닌 **물리 시뮬레이션 시간**입니다.
- 숨김 시 main 380에서 물리/시각 갱신을 멈추고 visibilitychange 421에서 프레임 시간을 초기화합니다. 실제 자동화 Chrome에서는 탭 전환/최소화/CDP freeze 후에도 document.hidden=false였고 경기가 진행됐습니다. 이를 실제 숨김 복귀 검증 성공으로 기록하지 않습니다.
- 재현 수정은 seed·설정·실제 starts를 저장합니다. 시작 전 버전/맵/물리/스킬 signature 및 ID·수량·유한수·spawn 위치·속도를 검증합니다(hand-start 9). 설정 변경 시 기존 UI가 seed를 비워 새 출발로 바꾸며, 재현 버튼을 다시 누르면 직전 설정 전체를 불러옵니다(ui 103). 구버전에는 출발 기록이 없어 재현 버튼을 비활성화합니다(ui 265).
- **시드 호환성 영향:** 원본 경기·출발 계산은 그대로입니다. 같은 시드+같은 출발을 넣으면 원본과 같은 결과입니다. 이전 “재현” 동작은 새로운 손 상태로 다시 시작했고 이제 저장한 출발로 즉시 시작하므로 그 경로의 결과가 달라지는 것이 의도된 수정입니다. 향후 물리 변경에는 replay signature 버전을 갱신해야 합니다. 엔진 간 전체 재현은 미검증입니다.

### C. 결과 판정

- 결승 교차는 이전/현재 y를 이용해 tick 내부 도착 시간을 보간하고 시간→입력 순서로 정렬합니다(physics 581–591). 제조한 동시 도착 회귀 검사도 같은 규칙을 확인했습니다(`qa/oracle.test.cjs`).
- 이름 1~500(physics 63–91), 그룹 8가지/총 500(24–61), 빈 값/501/소수/0은 거부합니다. UI의 N select는 1~총수량이며 시작 guard도 정수·범위를 확인합니다(main 221). headless 오라클은 유효 1/중간/전체 N을 전원 도착에 교차 검증하며, 0/초과/소수는 `qa/boundaries.test.cjs`에서 실제 start guard로 검증합니다.
- 실시간 상위 5행은 표시 선두만 0.45초 지연하고 완주는 즉시 처리합니다(ui 490, race-standing 19). 결과는 physics.finished를 복사합니다(main 307). 중도 종료 때 미완주 공에 가짜 순위를 붙이지 않으며 꼴등·미충족 N은 당첨 미확정입니다(main 300). 기존 integration 중도 종료 회귀를 재실행했습니다.
- 막힘 방지는 모든 미완주 공에 동일한 progress/delay 조건을 적용합니다(physics 569–579). 방향은 공 ID별 시드로 선택하고 반복 시 교대합니다. 이것이 우승 분포를 보존한다는 뜻은 아니며 ON/OFF 비교를 수치 부록에 기록합니다.

### D. 입력·보안·저장

- 새 UI에는 자유 이름 입력이 없고 숨김 names를 색상 선택으로 생성합니다. parseNames는 <>를 거부합니다(physics 82). 결과/순위/토스트는 textContent/createElement(ui 508, 532, 545, 570)입니다. 실제 browser storage `<img onerror>`와 직접 결과 라벨 렌더링에서 실행 0, 삽입 img 0을 확인했습니다(`browser-before.json`, `browser-edge.json`).
- settings/legacy 저장 JSON은 normalize/try-catch(main 34–55), last-round는 ui 43–46과 replay 시작 검증입니다. 손상 JSON, null, 배열, 잘못된 물리 값, 접근 자체가 예외인 localStorage에서 intro 부팅을 확인했습니다. 구버전 이름은 수량을 유지하며 색상으로 변환하는 의도된 마이그레이션입니다.
- production eval/외부 CDN 스크립트/런타임 fetch·XHR·WebSocket은 없습니다. qa adapter의 new Function은 신뢰한 저장소 소스 실행용이며 production에서 로드되지 않습니다. npm audit 결과는 `qa/results/npm-audit.json`(취약점 0)입니다. ### E. 리소스·품질·오디오
