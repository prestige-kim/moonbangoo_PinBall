## 조사와 조정

- 기존 버전4는 개발용 동일 시드50개 비교에서 약25~30초, 기본 맵은 약55~65초였다. 장애물의 총 개수보다 충돌 없이 내려가는 긴 통로가 문제였다.
- 초기 선반 설계에서 외벽 우회로가 발견되어 양쪽 선반을 벽까지 연장했다. 벽을 타는 단일 공도 여러 동적 선반에 부딪히는 별도 회귀 검사를 추가했다.
- 20구간·경사0.30rad 시안은 별도 표본에서 단일 공 중앙값이 기본 대비27% 길어 실패했다. 결과를 summary의 previousRevision에 남겼다. 해당 시드는 조정용으로 전환하고, 최종 경사0.34rad·핀 간격210으로 고정한 뒤 새로운 `library-pace-confirm-v5b-` 표본을 사용했다. 검사 기준을 완화하지 않았다.
- 강제 감속·타이머 대기·보이지 않는 힘으로 시간을 늘리지 않았다. 공통 물리 엔진과 속도 설정은 그대로이며 실제 선반 접촉과 경로 변경으로 진행 시간을 맞췄다.
