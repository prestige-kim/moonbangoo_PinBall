# 맵별 셔플 배경 전환 및 박자 분배기 문구 정리

2026-10-14. 시작 HEAD `15feff8cf7918ef1b0ed19b0672aa63ee4d109a8`, 분기 `codex/four-maps-local`. 배포/원격 기준 `5d25319ddd2d352cf35e314da27329c97daec397`를 포함한다. 같은 세션의 실서비스26개 파일 대조 증거는 `rhythm-clockwork/deployment.json`; 이번 작업은 해당 근거를 참조하며 새 Pages 배포를 수행하지 않았다.

## 요청 반영

게임 설정에서 맵을 선택하는 동안에는 기존 시작 배경을 유지한다. 게임 시작 버튼을 눌러 셔플로 들어가면 종이색에서 선택한 맵의 실제 경기 배경으로 1.6초간 부드럽게 교차 전환한다. 전환 양끝의 속도를0으로 하여 갑자기 켜지고 끝나는 느낌을 줄였다. 모션 줄이기 설정에서는0.12초로 줄인다. 다시 시작하면 전환도 처음부터 시작한다.

| 맵 | 셔플부터 경기까지의 배경 |
|---|---|
| 자개 핀 보드 | 자개빛 청록·아이보리, 물결과 물고기 무늬. 기본 코스의 외부 배경색만 갱신하고 판/장애물은 유지 |
| 갈래 서가 | 갈색·베이지, 책과 서가 무늬 |
| 빗살 낙하 | 살구·구리색, 엇갈리는 층과 사선 무늬 |
| 박자 분배기 | 자주·남색, 원형 시계 눈금과 기계 무늬 |

셔플 배경을 별도로 중복 제작하지 않고, Renderer가 캐시한 동일 맵 배경을 셔플/발사에 합성한다. 발사 직후 종이색으로 돌아가던 기존 그리기도 교체했다. 매 프레임 새 이미지나 무늬를 생성하지 않는다. 기존 기본 맵 배경색 변경은 사용자가 요청한 네 가지 배경 구분을 위한 의도적 변경이다. 다른 세 맵은 경기 배경의 색과 무늬를 그대로 셔플에 연결한다.

박자 분배기 코스의 드럼명(분배/엇박/합류/피날레), 우회·직통, 둥·짝·팅 문구를 모두 제거했다. 시계 눈금, 박자 점등, 움직이는 날개와 패드는 유지한다. 설정의 맵 이름, HUD, 공 이름과 결과 안내는 게임 조작 정보이므로 유지한다. 어두운 셔플 배경에서 붓기 안내는 밝은 색으로 표시한다.

## 검증 및 보존

- 셔플 전환의 시작/중간/끝, 재시작 시 초기화, 모션 줄이기를1개/50개 공으로 검사. 렌더 전후 공/셔플 몸체/RNG 소비가 같음을 확인한다.
- 발사0/0.5/0.999 시점에서 같은 맵 배경을 불투명하게 사용하고, 정확한 착지 끝점은 기존처럼 투명하게 넘겨주는지 검사한다.
- 박자 분배기의 모든 전용 장애물을 세 물리 시점에서 그려 텍스트 그리기 호출이 없는지 검사한다.
- 기존 배포 해시 검사가 의도적 배경 변경3개 파일을 감지했다. 원래 배포 해시는 fixture에 보존하고 별도 `intentionalVisualChanges`에 이유와 검토한 새 해시를 기록했다. 나머지 보호 파일/음원 해시 검사를 유지한다.
- 실제 브라우저에서 네 맵 각각 설정 선택→게임 시작→셔플 배경을 확인하고 캡처했다. 박자 분배기는 유리관 붓기→출구로 던지기→발사→경기까지 이어서 확인했다. [네 맵 캡처](map-backgrounds/preview.html), [발사](map-backgrounds/rhythm-flight.png), [경기](map-backgrounds/rhythm-race.png).
- [운영 파일 보존 기록](map-backgrounds/preservation.json): 시작 후보와53개 파일이 동일하다. 이번 운영 변경은 HTML 캐시 키와 JS4개뿐이다. 지형/물리/셔플 솔버/출발 재현/입력/카메라/음원/UI/CSS/에셋은 변경하지 않았다. 지형 버전도 유지해 기존 출발 기록과 호환된다.

보호된 미커밋 `qa/fairness/freeze.cjs`, `AGENTS.md`, `docs/RELEASE_MANAGEMENT.md`, fairness confirm 결과는 수정하거나 커밋하지 않는다. 최종 후보는 이 문서를 포함하는 로컬 커밋이며 운영 변경 해시를 preservation.json에 기록한다. 원격 반영/PR/main 병합/배포 허가가 없으므로 로컬 작업까지만 수행한다. 모바일 실기기와 배포 후 검증은 이번 범위가 아니다.
