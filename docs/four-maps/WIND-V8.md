# 갈래 서가 — 3.5초 간격의 손그림 바람 애니메이션

사용자는 “3~4초”가 한 번 부는 지속 시간이 아니라 **분출 간격**임을 답변으로 지정했다. 이에3.5초마다0.4초 분출하도록 바꾸고 지형 버전을8로 올렸다. 상승 높이·좌우 분산·송풍구 위치·크기·다른 장애물·공통 물리 엔진은 그대로다. 버전7 출발 기록은 지형 서명 검사에서 거부하며 버전8 출발 기록의 정확 재현18개를 확인했다.

첨부 참고 이미지의 가는 꼬리선, 둥글게 말리는 큰 덩어리와 작은 잔기류를 해석해 원본 Canvas 곡선으로 구현했다. 참고 이미지 파일이나 워터마크를 에셋으로 사용하지 않는다. 한 장의 이미지를 표시하거나 이동하는 방식이 아니다.

## 애니메이션

`Renderer.drawWindGust`가 물리 시계에 맞춰 매 렌더 프레임마다 꼬리 곡선·열린 외곽선·내부 말림·연필 같은 보조 선을 다시 계산한다. 좁은 꼬리에서 시작해 바람 덩어리가 위로 이동하며 커지고 좌우로 퍼진 뒤 투명해진다. 큰 덩어리와 작은 잔기류는0.07초 시차를 둔다. 물리 분출0.4초 뒤 남은 기류가 약0.75초까지 옅어지며 사라지고, 다음3.5초 주기 전까지는 대기 상태다.

직전 황동 송풍구·압력계·표시등·책 문양은 유지했다. 압력계와 표시등도 새3.5초 주기와 같은 시간으로 움직인다. 화면 효과 줄이기는 곡선 위치를 고정하며, 절약 품질은 바람 덩어리를2개에서1개로 줄인다. 품질 설정은 물리에 영향을 주지 않는다.

[프레임별 비교](wind-v8/frames.jpg)와 [직접 재생 미리보기](wind-v8/preview.html)는 게임에서 쓰는 실제 렌더러를 호출한다. 시작0.10초/확산0.30초/소멸0.55초를 비교하고 오른쪽 패널은 버튼으로3.5초 주기 재생을 확인할 수 있다. 이는 디자인 검증 화면이며 경기 녹화로 표현하지 않는다. 브라우저 콘솔 오류0개를 확인했다.
