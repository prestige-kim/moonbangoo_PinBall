# 갈래 서가 바람 장치 — 시각 디자인 상세화

2026-10-14 사용자 요청에 따라 송풍구·상승 기류·다음 분출 표시를 다듬었다. 운영 변경은 `js/renderer.js`의 바람 그리기와 해당 HTML 캐시 키뿐이다. 송풍구 라벨까지 보이도록 화면 밖 그리기 제외 범위를50에서80단위로 넓혔다. 물리·힘·주기·지형 버전은 변경하지 않았다.

- 송풍구: 황동 테두리의 두께와 그림자, 청록색으로 움푹 들어간 그릴, 슬롯 하이라이트, 양쪽 세로 홈 마개, 중앙 책 문양 메달.
- 대기: 양쪽 압력계의 바늘과 안쪽으로 차오르는 분절 표시등. 바람이 계속 부는 것으로 보이지 않도록 상승 기류는 대기 중 그리지 않는다.
- 분출: 투명한 부피감, 넓은 기류와 얇은 밝은 중심선을 겹친 리본, 위쪽 화살표, 바깥으로 휘는 소용돌이, 서가에 어울리는 작은 종잇조각. 종잇조각은 물리 장애물이 아니다.
- 화면 효과 줄이기에서는 리본과 종이의 이동을 줄인다. 절약 품질은 리본12개→8개, 종이12개→6개로 줄이며 바람 동작에는 영향을 주지 않는다.

- 음악·셔플·입력·카메라·다른 맵과 갈래 서가 지형·물리를 직전 커밋과 바이트 비교,8개 파일 모두 그대로다. [보존 기록](wind-art/preservation.json). 바람 그리기와 화면 밖 제외 범위를 제외한 나머지 렌더러 메서드도 직전 커밋과 일치했다.
- 기존 바람 검사가 동일한 물리 시계·분출/대기 구분·상승과 좌우 이동·완주를 확인했다. 물리 변경이 없으므로 과거108개 설정 조합과 경기 시간 비교를 새로 실행한 결과처럼 보고하지 않는다.

- 이번에는 실물 휴대폰과 게임 전체의 새 성능 측정은 하지 않았다. 그리기는 보이는 바람 장치에만 수행하며 입자 수 상한을 둔다.
