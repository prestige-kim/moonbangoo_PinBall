# 갈래 서가 동적 결승 구간 — 2026-10-14

사용자의 추가 요청에 따라 버전5에서 비워두었던 y8800~11000 구간을 동적 코스로 바꾸고 지형 버전을6으로 올렸다. 기존의 마지막20% 무장애물 규칙은 이번 요청으로 대체된다. 기본 맵·다른 맵·음원·물리 엔진·셔플·카메라·입력 코드는 수정하지 않았다. 운영 파일 변경은 갈래 서가 지형과 해당 HTML 캐시 키다.

- y9020: 반대 방향으로 회전하는 책갈피3개. 길이150, 회전 속도±1.6rad/s.
- y9600: 벽에서 이어지는 좌우 책 수레2개. 서로 반대 위상으로28단위 이동하고 경사는±0.5rad.
- y10160: 중앙 반납 선반1개. 좌우60단위 이동, 경사-0.55rad, 길이360.
- y10760: 마지막 회전 책갈피3개. 결승선은11000이며 회전 반경과 두께를 뺀 마지막 낙하 거리는 약157단위다. 약2000단위 무장애물 낙하를 없앴다.

결승 구간 동적 장애물은 총9개이며 기존20개 서가 구간은 유지한다. 모든 장치의 이동/회전은 공통 물리 엔진의 실제 충돌과 표면 속도로 처리한다. 보이지 않는 감속·타이머 대기·강제 구조는 추가하지 않았다. 120Hz로8초간 전체 장애물 쌍과 벽의 열린 통과 간격을 검사했다. 회전 장치 간 최소 보수적 간격은104단위, 벽과의 간격은111단위이며 기존 코스까지 포함한 검사 기준96을 통과했다.

## 검증

전체 테스트265개 통과. 최종 지형에 대해 설정 조합108개(공1/2/6/25/49/50, 반지름8/16·중력350/1500·반발력0.35/0.92의 극단값 포함)와 실제 출발18개 정확 재현 통과, 실패0개. 마지막 회전 장치의 실제 충돌 이벤트와 결승 구간의 깊은 관통 여부도 별도5개 맵 검사로 확인했다. 모든 검사 경기는240초 상한 내 완주했으며 모든 시드의 무정체를 보장한다는 뜻은 아니다.

기존과 같은 허용 범위를 유지하여 새 시드60쌍120경기에서 비교했다. 공 수1/6/25/50 각각15쌍, 동일한 출발 좌표·속도와 기본 물리 설정·스킬 끔으로 비교했다. 단위는1배속 환산 물리 시간이며 마지막 공 완주 기준이다.

| 공 수 | 기본 맵 중앙값 | 갈래 서가 중앙값 |
|---|---:|---:|
| 1 | 43.1초 | 49.6초 |
| 6 | 52.3초 | 54.1초 |
| 25 | 59.9초 | 60.1초 |
| 50 | 60.6초 | 58.2초 |

중앙값 비율0.8~1.2,90백분위 비율0.7~1.3을 모두 통과했다. 첫 시안에서는 단일 공 중앙값이 약24% 길어 실패했다. 반납 선반 길이·경사를 조정한 뒤 별도 `library-pace-finale-v6b-` 시드로 재검증했다. 실패 시안 요약도 [summary.json](twinfold-finale/summary.json)에 보존했다.

인앱 브라우저에서 직접 붓기·발사·결승 통과를 조작했다. 최종 지형으로12개 경기 전원 완주, 경기 시간56.66초(3배속 실행의 물리 시간 표시)를 확인했다. [결승 장치 화면](twinfold-finale/play.jpg), [결과 화면](twinfold-finale/result.jpg). 실물 휴대폰 및 새 지형의 대규모 추첨 확률 검사는 수행하지 않았다.
