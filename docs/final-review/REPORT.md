## 실제 실패와 수정 결과

[수정 전 재현](library-stall-before.json): 도서관 v8, 크기 12·중력 620·반발력 0.72·스킬 OFF에서 (500,738), vx=0, vy=0으로 놓은 공은 책받침 꼭대기 (500,1235.985)에 머물며 240초까지 완주하지 못했다. 고정된 원형 꼭대기에서 수평 대칭이 유지되는 실패다.

수정 후 동일 좌표는 **47.425초**, 고체 접촉 39회로 완주했다. x=499.5/500/500.5 × y=737/738/739의 9개 인접 좌표도 모두 완주했고 구제 동작은 없었다. 실제 완주 회귀 검사를 tests/twinfold.test.cjs에 추가했다. 추가 좌표 검사는 27개 극단 물리 조합에서 두 수정 맵 각각 x=499.5/500/500.5, y=750−반지름으로 검사했다(162건). 첫 접촉에서 멈추지 않고 전체 코스를 끝까지 실행했다.

기존 6,000경기 원자료를 합의한 집계법으로 읽으면 협곡 v5의 공 1개 중앙값은 기본맵의 약 114.86%, 공 3개는 약 111.30%로 실패했다. v6 최종 결과는 두 조건을 포함해 모두 통과했다. 기존 원자료와 [중단 전 문서](REPORT-before-resume.md)는 보존했다. 최초 원자료의 '21개 실패'는 공 수별 p95까지 비교한 이전 기준이며 현재 판정에 전용하지 않는다.

## 시간 기준과 재사용

기본 물리: 크기 12·중력 620·반발력 0.72·스킬 OFF. 시간은 물리 시뮬레이션 시작부터 마지막 공이 도착할 때까지다. 공 수 1~50, 출발 방식 B/C/D 각각 같은 10개 시드, 맵별 1,500경기다. 이전 6,000경기와 동일한 `final-holdout-v2` 시드와 실제 출발 생성 코드를 사용하고, 각 출발 좌표·속도가 기본맵과 같음을 확인했다. 별도의 대규모 확인 시드는 추가하지 않았다.

중앙값은 중단 보고서와 동일하게 짝수 표본의 가운데 두 값을 평균한다. p95는 nearest rank(ceil(n×0.95))로 각 맵의 1,500경기를 합쳐 구한다. 원자료 audit-pace.json의 옛 집계는 아래쪽 중앙값과 공 수별 p95를 사용했으므로 원자료의 pass 플래그를 재사용하지 않고 **모든 맵의 원시 시간들을 동일한 합의 집계법으로 다시 집계**했다. 기준은 공 수별 중앙값 90~110%, 맵 전체 p95 90~110%다.

- 기본 설정: 도서관·협곡 3,000경기를 새로 실행. 기본맵·태엽 공장 3,000경기를 [원자료](audit-pace.json)에서 재사용.
- 극단 설정: 크기 8/12/16 × 중력 350/620/1500 × 반발력 0.35/0.72/0.92 × 공 수 1/2/6/25/49/50 × B/C/D = 맵별 486경기. 도서관 v9 486경기를 새로 실행. 협곡 v6 486경기는 완결된 [앞선 검사](approved-extremes.json)에서 재사용. 기본맵·태엽 공장 972경기는 같은 파일에 보존된 원래 기록에서 재사용했다.
- 재사용은 맵별 지형·공통 물리·출발 생성 코드의 해시가 같을 때만 허용했다. 원자료에 없는 출발 의존성 해시는 생성 당시 커밋 1df5c56과 대조했다. [최종 원자료](candidate.json)의 reuseChecks/provenance에 경로별 근거를 기록했다.
- 중단된 retest/confirm은 진행 로그만 있고 완결된 경기별 기록이 없어 사용하지 않았다. first-contact routes 검사는 반복하지 않았고, 이전 지형의 결과를 최신 후보의 통과 증거로 사용하지 않았다.

|---|---|---|---|---|
| 연못 정원 | v2 | 100.00%~100.00% | 66.292초 / 100.00% | 통과 |
| 바람 도서관 | v9 | 94.22%~107.73% | 63.108초 / 95.20% | 통과 |
| 빗살 협곡 | v6 | 91.26%~108.88% | 65.992초 / 99.55% | 통과 |
| 태엽 공장 | v5 | 90.33%~102.75% | 64.600초 / 97.45% | 통과 |

세 추가 맵의 중앙값 150개 조건과 전체 p95 3개 조건 모두 통과했다. 세부 공 수별 수치와 시드별 경기는 [candidate.json](candidate.json)에 있다.

## 구조적으로 확인한 사실과 한계

[후보 구조 검사](structure.json)는 도서관의 첫 이동 서가들이 모든 위상에서 직선 낙하의 빈 공간을 다음 서가로 덮음, 협곡의 7개 고정 경사로 쌍이 전체 가로 폭을 덮음을 확인했다. 태엽 공장의 공급 통로와 첫 6날개 드럼은 문서의 중력·속도·상대 회전 전제에서 직선 무접촉 경로를 차단한다. 원래 서가·드럼 구조를 유지해 이 성질을 보존했다.

이 구조 확인은 수평 속도 0인 직선 낙하에 한정된다. 공끼리 충돌한 뒤의 모든 궤적, 모든 실수 좌표·장애물 위상·무한한 시드, 모든 시간 분포를 보장하지 않는다. 시드당 유한 표본의 중앙값/p95 통과는 미실행 시드의 동일 비율을 보장하지 않는다. 이전 첫 접촉 검사에서 정지 문제를 놓쳤다는 사실을 유지하며, 첫 접촉과 전체 완주를 구분한다.

이번 최종 브라우저 검사는 데스크톱 Chrome의 두 수정 맵에 대한 것이다. 과거 다른 맵·모바일 터치 에뮬레이션 결과는 역사적 자료로 남겼으며 최신 수정 맵의 모바일 검증으로 주장하지 않는다. 실물 휴대폰, 모든 브라우저/기기, 실제 스피커 청취, 제품 FPS는 이번 범위에서 검증하지 않았다. 성능 측정용 대규모 검사는 추가하지 않았다.

## 배포 승인 전 검토 종료 상태

합의한 범위 안에서 알려진 실패를 수정하고 최종 후보 검사 한 차례를 완료했다. 추가 재설계·반복 경기 검사·확인용 시드 검사를 하지 않았다. 결과물은 로컬 커밋과 문서이며 원격 main 및 운영 서비스는 기존 5d25319 상태다. 배포 시에는 사용자 별도 허가 후 원격 이동 여부를 다시 확인하고, Pages 소스 SHA·서비스 파일 해시·대표 서비스 동작 검증이 필요하다. 위 문단은 승인 전 검토 종료 당시 상태다. 이후 승인·배포·서비스 확인은 [배포 기록](deployment/REPORT.md)에 남겼다.
