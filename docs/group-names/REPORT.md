## 변경과 호환성

표준 HTML 텍스트 입력창으로 한글·영문·숫자 및 쉼표·별표를 포함한 그룹 이름을 입력한다. 기존 색상 버튼과 수량 버튼·드롭다운을 유지하며, 그룹마다 이름·8색 중 색상·수량을 지정하고 그룹을 추가·삭제할 수 있다. 총 공 50개 제한 내에서 최대 50개 그룹을 만들 수 있다.

그룹 ID, 이름, 색상, 수량을 `groupVersion: 1` JSON 문자열로 기존 `names` 설정 필드에 저장한다. 중복 이름은 Unicode NFC 정규화 및 앞뒤 공백 제거 후 검사한다. 빈 이름·40자 초과·제어 문자·꺾쇠 괄호·유효하지 않은 개수/색상/식별자는 거부한다. 미완성 이름은 마지막 정상 저장값을 덮지 않는다.

기존 쉼표·줄바꿈·`이름*개수` 설정도 계속 읽는다. 기존 기록을 불러올 때 이름·순서·개수 및 기존 문자열을 보존하므로 직전 경기의 출발 기록·시드를 그대로 재현할 수 있다. 물리 계산과 출발 기록 v2의 서명·복원 조건은 바꾸지 않았다. 새 이름/색상을 쓰는 경기는 새 설정으로 저장하며, 직전 게임 재현을 선택하면 당시 이름·색상도 복원한다. 구형 배포 코드는 새 그룹 JSON 형식을 지원하지 않으므로 구형 코드로 되돌릴 때 새 설정의 역변환은 별도로 필요하다.

입력 중에는 DOM 입력창을 교체하지 않아 IME 조합·커서를 유지한다. 조합 중 키를 가로채지 않고, 이름 칸 Enter는 입력 완료로 처리해 자동 출발을 막는다. Escape는 이름 칸의 포커스를 해제한다. 설정창 진입 시 예약된 포커스가 사용자의 빠른 입력을 가로채지 않게 했다. VisualViewport에 맞춰 설정창을 배치하고 가용 높이가 작을 때 제목·하단 여백을 줄인다. 변경 파일의 캐시 URL도 실제 콘텐츠 해시로 갱신했다.
