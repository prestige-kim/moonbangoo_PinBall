## 실제 게임에 포함할 내용

1. 맵별 장애물 재질 이미지와 종이·갈색 인쇄·금박 스타일의 배경v2. 준비·셔플·발사·경기·결과의 선택 맵 연동 및 이미지 지연 캐시 갱신.
2. 협곡v7: 이전에 만든 바위 받침11개. 기존 원본 지형·이미지를 삭제하지 않는다.
3. 고정 카메라의 종이→놀이판 발사 전환. 짧은 관성 후 실제 확정 출발 슬롯으로 연결하며 실제 경기 렌더러를 사용한다. 물리·RNG·출발 슬롯은 바꾸지 않는다.
4. 도서관v10: 중앙 후반 책받침 하나를 높이와 박자가 다른 두 책받침으로 교체한다. 검토 시안의 맵 객체와 정확히 같은 데이터임을 비교했다(geometry-parity.json).
5. 과거 배경·전환·긴장감 비교 페이지를 유지한다. 기존 전환/도서관v9를 별도 보존 파일에서 불러와 과거/현재 비교가 무너지지 않게 한다. 루트 게임은 개선 전환과 도서관v10을 직접 사용하며, QA 플러그인에 의존하지 않는다.

## 알려진 제한 — 이번 승인으로 사라진 것이 아님

- 협곡v7은 이전1500경기의 공수별 중앙값111.21~137.86%, 맵 전체p95 118.08%로 ±10% 시간 기준을 실패했다. 이번 배포에서 그대로 포함하며 추가 조정하지 않는다.
- 도서관v10 시안은54경기에서 후반 교체54→59회,75% 선두 우승률66.7→61.1%의 작은 변화였다. 기본6개의 후반 교체는 늘지 않았다. 확실한 긴장감 개선이나 모든 경기 역전을 보장하지 않는다.
- 도서관 후반 임의좌표18건은 모두 완주했지만12건은 이후 고체 접촉 없이 도착했다. 정상 출발의 극단24건은 모두 완주·접촉했으나, 이를 모든 좌표·시드·설정 통과로 해석하지 않는다.

## 검증 방법과 기대값 변경

기존 발사 테스트 중 큰 추진·0.12초 출발 지연·초반 줌아웃·끝까지 불투명한 종이 배경은 승인한 전환과 충돌하는 기대값이었다. 이를0.04초 지연·작은 추진·고정 카메라·전반 디졸브로 갱신했다. 출발 좌표/속도의 연속성, 정확한 끝점, 물리/RNG 불변, 전체 공의 화면 내 표시와 리사이즈 연속성은 유지한다. 화면 표시 검사의 카메라는 실제 prepareLanding을 사용해 가로형 화면에서도 실제 경기의 도착 프레이밍을 반영한다. 큰 추진을 기대하던 숫자를 줄여 시간/충돌 실패를 감춘 것이 아니다.

도서관의 버전·마지막 단계 개수 기대값도 실제 승인 형상으로 갱신했다. 보호 해시는 기존 배포 해시·직전 시각 변경 해시·사유를 보존한 채 발사 파일의 의도한 변경을 기록한다.

중단한 전체 검사 로그는 tests-interrupted.log로 보존하고 최종 통과 증거로 쓰지 않는다. 최종 전체 테스트·브라우저 결과와 배포 SHA/서비스 검증은 아래에 추가한다.
