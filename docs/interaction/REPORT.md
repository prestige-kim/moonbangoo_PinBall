# 인터랙션·시각 품질 검증

> 이 문서는 `e48358f` 시점의 5개 개선에 대한 기록이다. 이후 사용자가 승인한 실제 원형 셔플 변경은 [최신 원형 셔플 보고서](CIRCULAR-GRAB.md)를 우선한다. 아래의 “셔플 계산 불변” 및 이전 전후 상태 동일성은 새 원형 셔플에는 적용하지 않는다.

작업 브랜치: `release-check/interaction-quality`. 기준 커밋: `78b23b4`.
원본 `release-check/fairness-fix`의 미커밋 시간 안내 작업과 중지된 공정성 후보 측정 두 개를 보존했다. 감사는 아직 완료되지 않았다. 이번 브랜치는 그 커밋의 프로토콜을 그대로 유지하며, 공정성 해소나 배포 승인을 주장하지 않는다. 원본의 미커밋 시간 안내는 이 별도 작업 트리에 복사하지 않았다.

## 검증 결과

- `npm run qa`: **205개 통과, 실패 0**. 최종 로그를 `qa/interaction/results/qa.txt`에 보관한다. 초기 실패 로그(`qa-initial.txt`, `targeted.txt`)도 보존하며, 초기 표시 좌표 계약·비행 시작점·CSS 캐시 버전 문제는 수정 후 재검증했다. `browser-log.txt`에는 캡처 뒤 잘못된 순위 selector로 종료한 초기 실행이 남아 있으며, 수정 후 최종 조작 검사는 `browser-checks-log.txt`에서 모두 통과했다.
- 새 검사 `qa/interaction.test.cjs`: 5개 통과. 동일 시드와 고정 입력에서 표시 호출만 30/60/120Hz로 달리해도 수정 전의 출발 기록·완주 순서·정확한 완주 시간이 일치한다. 이는 실제 모니터 주사율 벤치마크가 아닌 표시 호출 빈도 검사다.
- 로컬 `/moonbangoo_PinBall/`: 브라우저 오류·실패 요청·HTTP 오류 0. 색상 그룹 제거·재추가, 공 수 3→2, N번째 순위 및 세부 설정을 실제 요소로 조작한 뒤 마우스/합성 터치 각 6개 완주, 직전 게임의 출발 기록·완주 순서·시간 일치. 터치는 `low`와 reduced-motion ON을 사용했다.
- 6/50/200/500 × 1280×720 / 390×844 / 844×390: 수정 전후 동일 시드·동일 기울이기·동일 원형 동작. 매 인계에서 위치·반경·속도 오차 < 1e-12, 복제·누락 없음. 같은 계산 시간을 120Hz 고정 계산, 15fps로 캡처했다. 영상 10초에 관 대기·기울이기·낙하·바닥·셔플·정지를 포함한다.
- 360×640 / 390×844 / 768×1024 / 1280×720 / 1920×1080 × DPR 1/2/3: 설정 시작 버튼과 실제 경기의 카메라 버튼 모두 가리지 않음. 가로 844×390 × DPR 1/2/3도 추가 확인. 가로 넘침 0. 설정 기본 스크롤 및 캔버스 `touch-action:none` 유지.
- 맵/경기 물리/셔플/셔플 입력/참가자 슬롯 프로토콜/출구 판정/cinematic 7개 모듈은 기준 커밋과 바이트 단위 동일. `stepPour`와 `updateRace` 함수도 동일. 계산 상수·지원 범위·스킬·막힘 방지·당첨 규칙은 변경하지 않았다. 별도 공정성 표본을 실행하지 않은 이유는 실제 유리관·셔플 계산을 변경하지 않았기 때문이다. 기존 감사에서 발견한 편향이 해소됐다는 뜻은 아니다.

## 사람이 확인할 사항과 한계

1. 실제 iPhone/Android에서 추가 손가락, 브라우저 가장자리 제스처, 손 떼기, 화면 회전 후 기울이기·출구 발사가 자연스러운지 확인한다. 합성 터치는 OS 제스처를 재현하지 못한다.
2. 500개를 실제 저성능 기기에서 조작해 프레임 저하와 입력 반응을 확인한다. 이번 표시 버퍼는 공 수만큼 한 번 할당하고 재사용하지만, 기존 충돌 계산의 비용까지 줄인 것은 아니다.
3. 전후 영상에서 관 배출 흐름과 질감의 취향상 적합성을 확인한다. 2.5px 공에서는 색 외 식별 링의 틈까지 읽기 어렵고, 기존 중력·접촉에 의한 미세 움직임은 남는다. 물리적 배출 순서·시간을 인위적으로 벌리지 않았다.
