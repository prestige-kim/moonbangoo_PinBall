# 모든 공을 담는 원형 셔플

사용자가 “모든 공을 원 안에 모으고, 손을 움직이면 원 전체가 따라오게 하기”를 선택했다. 이번 변경은 **표시만의 변경이 아니라 실제 셔플 계산 변경**이다.

## 구현

- `js/hand-scene.js`: 준비 완료 후 하단 출구 안내 문구 제거. 관 기울이기 안내는 유지. 원의 표시 중심은 실제 원형 벽 중심과 일치한다.
- `js/shuffle.js`: HandScene에서만 원형 잡기를 활성화한다. 공을 잡으면 전체 공 무리의 중심을 구해 같은 비율의 기하학적 변환으로 원 안에 모으고 기존 충돌 계산으로 겹침을 해소한다. ID·색상별 배치·지연·순서를 새로 부여하지 않는다. 반경과 ID를 유지한다.
- 손 이동은 원과 모든 공의 위치를 함께 이동시킨다. 손의 가속·감속은 원 내부 좌표계의 관성으로 전달한다. 원 가장자리에서 공 반경까지 고려해 접촉을 보정하고 기존 셔플 벽의 반발·마찰 계수를 적용한다. 잡고 있는 동안 사각 구역 전체 대신 원 내부를 충돌 공간으로 사용한다.
- 원이 화면 밖으로 잘리지 않도록 중심을 기존 영역 안으로 제한한다. 손이 출구로 이동하는 입력은 기존 ThrowGate에 그대로 전달하므로 기존 출구로 던지기가 가능하다.
- 손을 놓거나 취소하면 원을 해제하고 내부 속도를 화면 좌표계의 속도로 변환한다. 이후 기존 바닥·벽 계산과 출발 기록 경로를 사용한다.
- 경기 맵·경기 물리·스킬·구제·당첨 규칙·참가자↔슬롯 프로토콜·재현 기록 형식은 변경하지 않았다. 경기 RNG는 사용하지 않는다.

## 검증

- `qa/shuffle-boundary.test.cjs`: 6/50/200/500 공의 실제 원 경계 내부 유지, ID·반경 유지, 원 벽 반사, 손 이동·화면 경계·놓기 속도, 표시 빈도별 결정론, 안내 제거 검사.
- `qa/interaction.test.cjs`: 최신 원형 셔플의 동일 시드·고정 입력에서 표시 호출 30/60/120Hz에 따른 출발 기록·완주 순서·완주 시간 일치. 이전 셔플과 같은 결과라고 주장하는 검사는 최신 셔플 내의 결정론 검사로 변경했다.
- `qa/circular-grab/browser.cjs`: 데스크톱/세로/가로 × 6/50/200/500의 12개 실제 렌더링 사례에서 원 밖 공 0, 표시·계산 위치 오차 <1e-9, ID 누락 0, 경기 RNG 사용 0. 실제 마우스·합성 터치 각각 잡기→원 이동→놓기→출구 던지기→6개 완주→직전 재현 일치 확인.
- `npm run qa`: **210개 통과, 실패 0**. 새 원형 결과의 전체 QA 로그: [qa.txt](../../qa/circular-grab/results/qa.txt). 초기 5개 개선의 205개 QA 로그는 과거 증거로 따로 유지한다.
- [브라우저 원시 결과](../../qa/circular-grab/results/browser.json), [계산 변경 구분](../../qa/circular-grab/results/invariants.json), [마우스로 잡은 상태](../../qa/circular-grab/results/held-mouse.png), [터치로 잡은 상태](../../qa/circular-grab/results/held-touch.png).

## 공정성 상태

**최종 공정성은 미검증이다.** 기존 감사 결과나 기능·결정론 검사로 공정성 합격을 주장하지 않는다.

[별도 사전 등록](../../qa/circular-grab/PLAN.md)에 기존 ID/그룹 χ² p≥0.01 및 최대편차≤1.5pp, Wilson95% CI, 새로운 dev/holdout 구획을 고정했다. 새 dev pilot는 시간·종료성만 측정하며 N20/경로로 최종 판정을 하지 않는다. 4 worker pilot 80판은 11.18초에 80판 모두 완주했고 유한수·bounds·순위·오라클·종료 오류가 0이었다. 40,000판 추정은 93.2분으로 사전 45분 기준을 넘어, 추후 최종 표본은 경로당 N5,000으로 적용한다(기대율 근처 Wilson95% 반폭: ID 약1.03pp, 그룹 약1.31pp). 이 추정에는 초기 실행 비용이 포함돼 실제 대규모 실행 시간과 다를 수 있다. 최종 holdout 및 N3,000 구성별 스크리닝은 **미실행**이다. [pilot 및 CI](../../qa/circular-grab/results/pilot.json), [원시 결과](../../qa/circular-grab/results/pilot-raw.json.gz). 원본 감사 브랜치의 미커밋 작업·중지된 후보 측정·시드를 건드리지 않았다.

## 실기기 확인

iPhone/Android에서 잡기·빠른 흔들기·손 떼기·추가 손가락·회전 후 원이 남지 않는지, 500개 조작 반응을 확인한다. 현재 브라우저 검사는 합성 입력과 데스크톱 Chromium에서 수행했다.
