# 어른뭉방구 배경 브랜드 검토

2026-10-15. 로컬 작업. push·병합·배포 금지 유지.

## 판단 근거

브랜드의 실제 [로고](../../assets/logo.png), 기존 종이·금박 화면, 별도 카드팩 프로젝트의 README와 design/lib/common.js를 참조했다. 카드팩 프로젝트는 어른뭉방구를 포항 종합 문구점으로 설명하고, 공통 팔레트는 종이 #F4EDE0/#FBF7EF, 갈색 인쇄 #4A3A28, 금박이다. 특정 시대의 복고풍이나 임의의 캐릭터를 공식 브랜드 규정으로 가정하지 않았다. 별도의 공식 브랜드 가이드가 주어진 것은 아니므로 이번 평가는 확인 가능한 기존 자산을 기준으로 한 시각 디자인 판단이다.

기존 v1 네 배경은 맵 소재는 잘 드러나지만 사실적 질감·판타지 장식·어두운 기계 묘사가 공통 종이·금박 디자인보다 강했다. 연못과 협곡도 같은 인쇄 삽화 재질로 정돈하고, 도서관과 공장은 장식 방향을 함께 수정했다.

| 맵 | v1의 문제 | 수정 방향 |
|---|---|---|
| 연못 정원 | 수풀·수면의 사실적 질감과 금색 얼룩이 조밀함 | 연꽃·잉어·갈대를 아이보리 종이 위 청자색 삽화와 금갈색 선으로 |
| 바람 도서관 | 유럽 고서·양피지·궁전풍 장식 비중이 큼 | 책·책갈피·종이·연필 등 문구 소재와 바람 선화 |
| 빗살 협곡 | 사암·화석의 자연환경 묘사가 브랜드 재질과 떨어짐 | 사암 층리·화석·자갈을 따뜻한 테라코타 인쇄 삽화로 |
| 태엽 공장 | 어두운 금속판과 스팀펑크 기계가 가장 이질적 | 밝은 종이 위 태엽·톱니·황동/청록의 기계 장난감 삽화 |

이미지 생성 스킬의 built-in image_gen으로 기존 배경과 실제 로고를 각각 편집 대상·스타일 참조로 지정했다. 로고 자체는 배경 안에 생성하지 않았으며 기존 로고 파일도 수정하지 않았다. v1 파일은 보존하고 v2를 별도 저장한다. 정확한 프롬프트와 참조 경로는 assets/backgrounds/manifest.json에 기록한다.
