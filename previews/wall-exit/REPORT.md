# 가상 벽과 경계 통과 즉시 발사 — 2026-10-07

## 변경과 범위

보이는 둥근 셔플 구역 안에서 공들이 벽에 튕기며 섞입니다. 실제 공에 영향을 준 드래그가 구역 안을 거쳐 벽 밖으로 나가면 손을 놓기 전에 기존 비행 → 경기 맵 진입을 시작합니다. 이전 최소 이동0.20S·가장자리 놓기·히스테리시스 조건은 최신 요청에 따라 제거했습니다. 느리거나 짧은 드래그도 안에서 밖으로 나가면 정상 진입합니다. 벽 밖 클릭/밖에서만 이동/공을 움직이지 않은 빈 영역 입력은 진입시키지 않습니다.

게임 좌측 상단의 별도 `어른뭉방구` 텍스트만 제거했습니다. 기존 로고 이미지·대기 화면·설정 화면은 유지합니다. 경기 물리 엔진·맵·규칙·순위·도착 시간·결과 화면·렌더러·비행 코드·입력 어댑터는 기준 `a968e56`에서 변경하지 않았습니다. 사용자 변경이 없는 깨끗한 Git 상태를 확인하고 필요한 셔플·판정·연결 코드만 수정했습니다.

## 물리와 판정 기준

- S = min(화면 너비−32px, 화면 높이−48px). 기존 표시 배율0.84를 좌표와 반지름에 함께 반영합니다.
- 둥근 벽은 보이는 내측 경계선과 같은 geometry입니다. 좌우16px·상하24px 기본 여백에0.14S를 더하고, 모서리 반지름은0.10S입니다. 공 중심의 허용 구역은 실제 공 반지름만큼 벽에서 안쪽으로 이동합니다. 표시/충돌 반지름은 일치합니다.
- 벽 바깥 방향 법선 속도에 반발계수0.52, 접선 속도에 마찰0.97을 적용합니다. 모서리에서는 둥근 벽 법선으로 반사합니다. 이미 안쪽으로 움직이는 공은 다시 반사하지 않습니다. 위치 보정은 충돌 관통 보정이며 전체 집합 위치·속도를 초기화하지 않습니다.
- 기존 거리별 입력 힘, 약한 중력·감쇠, 실제 입력 경로 회전, 공간 해시·적응 세부 스텝을 재사용했습니다. 500개도 각 ID와 개별 물체를 유지합니다.
- 실제 접촉 + 구역 안을 한 번 이상 거침 + 현재 포인터의 둥근 벽 signed distance >1e−9S이면 첫 유효 pointermove에서 한 번 발사합니다. 선을 만지기만 해서는 진입하지 않습니다. 최소 이동/속도는 없습니다. 최근160ms 이벤트 속도는 비행에만 반영합니다.
- 마지막 바깥 샘플이 pointerup에만 온 경우도 동일하게 처리합니다. 발사 후 캡처를 해제하고 뒤늦은 move/up/중복 up는 무시합니다. 벽 안에서 취소·포커스 상실·다중 터치·화면 회전 시 발사하지 않고 복귀하며 위치·속도를 초기화하지 않습니다.
- 접근 시 금빛 경계 피드백과 기존 줌 아웃·꼬리 제거를 유지합니다. 안내는 ‘벽 안에서 섞고 밖으로 끌어 주세요’ 한 줄입니다.

## 자동 검사

먼저 둥근 모서리 충돌과 손을 놓기 전 진입 재현 검사를 추가했고 이전 구현에서 실패함을 확인했습니다. [실패 로그](evidence/wall-baseline.txt). 수정 후 전체 `node --test tests/*.test.cjs` **133개 통과, 실패0개**, 약31초. [전체 로그](evidence/wall-all-tests.txt).

둥근 모서리/직선 벽·중복 반사 방지·안쪽 속도 보존, 6·50·200·500개 ×3크기의 벽 압박, ID·반지름·공간 해시, 취소·중복·시간 역전, 프레임 묶음0/1/4의 같은 첫 경계 통과, 발사 시 현재 상태·경기 시간0, 실제 슬롯과 완주 재현을 검사했습니다. 물리 스트레스 검사는 120Hz 3초, 12스텝마다 모든 쌍의 겹침을 측정했습니다. 최대 표본 겹침은 접촉 지름 대비0.8805%로 깊은 관통 기준5% 미만이며 모두 둥근 벽 안에 유지됐습니다. 표본 사이의 모든 순간까지 연속 측정한 수치는 아닙니다.

12조합 모두 합성 터치로 바깥 클릭·바깥 짧은 이동·빈 영역 드래그의 미발사, 벽 안 셔플의 위치 교환·공 충돌·벽 충돌·원형 벽 안 유지·ID 보존을 확인했습니다. 이어서 별도의 실제 마우스 `isTrusted:true` 입력과 실제 포인터 캡처로 **pointerup 이전 pointermove 발사**를 확인했습니다. 모든 조합의 `autoExit.sourceContinuous=true`, `upEventsBefore=0`, 발사 순간 경기 시간0, ID 연결=true, 실제 슬롯 진입 최대 오차0px. 비행25~75% 표본에서 모든 공이 화면 안에 보였습니다. 헤더 텍스트 DOM은12조합 모두 없습니다.

## 시드와 모션 감소

경기 시드나 슬롯 소유권을 바꾸지 않았습니다. 시각적 셔플은 실제 입력에 따른 비결정적 경로여도 각 공은 기존 시드로 할당된 자기 슬롯까지 비행합니다. 일반 게임의 새 시드 정책도 유지합니다.

실제 브라우저의500개 `EDGE-QA-500` 게임을 일반 모드의 벽 셔플+빠른 마우스 통과와 모션 감소 모드의 느린 합성 터치 통과로 완주했습니다. **전체 출발 슬롯·완주 ID·순위·도착 시간 배열이 정확히 일치**했습니다. 느린 통과 속도 약0.222S/초여도 즉시 발사했습니다. [비교](evidence/wall-repro.json), [일반](evidence/wall-normal-finish.json), [모션 감소](evidence/wall-reduced-finish.json).
