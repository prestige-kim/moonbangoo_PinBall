# 유리관에서 셔플 공간으로 붓기 — 구현 기록

직전 요청은 구현까지만 진행하도록 지정됐습니다. 아래는 그 연출의 설계 기록이며, 후속 검수에서 보정한 최종 타임라인을 반영했습니다. 2026-10-11 전체 검증·최적화 결과는 [REPORT.md](REPORT.md)를 확인하세요.

- 대기·설정 화면에서 유리관의 공을 움직이던 `previewChamber.seek` 호출과 공기압 발광을 제거합니다. 표시 배열은 고정됩니다.
- 설정한 참가자 전체를 기존 ID 그대로 받아 유리관을 들어 기울이고, 입구에 가까운 공부터 굴려 꺼냅니다. 사진 에셋과 Canvas 변환을 재사용하며 프레임 이미지나 새 대포·바퀴 에셋을 만들지 않습니다.
- 3.15초의 초 단위 타임라인: 0~0.65초 들어 기울이기, 0.72~1.97초 순차 배출, 각 공 약 0.65초 낙하, 2.65~3.15초 빈 유리관 퇴장. 렌더 프레임 번호에 종속되지 않습니다.
- 굴러 나오는 궤적의 끝 속도를 낙하 곡선에 전달하고, 낙하 끝 위치·속도를 그대로 셔플 물리에 넘깁니다. 먼저 들어온 공은 이후 도착한 공과 충돌합니다. 아직 관 안에 있거나 낙하 중인 공만 셔플 충돌에서 제외합니다.
- 전체 공이 들어올 때까지 드래그를 잠급니다. 이후의 우측 상단 출구 판정과 비행·경기 연결은 기존 흐름을 사용합니다.
- 모션 감소에서도 공을 순간 이동시키지 않습니다. 관의 기울기와 퇴장 이동을 줄이며, 연출 시작 시 설정을 고정하여 도중 설정 변경으로 위치나 시간이 초기화되지 않게 합니다.
- 경기 RNG, 실제 슬롯 소유권, 경기 물리·규칙·결과 계산은 변경하지 않습니다. 배출 순서는 시각적 유리관 위치를 기준으로만 정하고 참가자 배열을 재정렬하지 않습니다.

다음 검증에서 확인할 항목: 첫 프레임과 대기 화면의 위치 일치, 유리관 열린 입구와 배출 위치, 6·50·200·500개 낙하·충돌·성능, 데스크톱·모바일 세로·가로의 화면 밖 가림, 낙하→물리 전환의 위치/속도 연속성, 모션 감소 및 포커스 복귀, 모든 ID와 고정 시드 경기 결과 재현. 기존 검사 중 0.8초 추출 및 자동 대기 움직임을 전제한 항목도 새 요구사항에 맞춰 갱신해야 합니다.
