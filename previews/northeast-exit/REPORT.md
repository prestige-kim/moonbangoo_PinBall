# 우측 상단 대각선 출구 — 2026-10-11

## 변경

셔플 구역을 두께 있는 따뜻한 색의 둥근 레일로 둘렀습니다. 우측 상단만 레일을 끊고 금빛 대각선 화살표로 출구를 표시합니다. 항상 보이는 화살표와 출구 접근 시 밝아지는 피드백, ‘우측 상단 출구로 공을 끌어 주세요’ 안내 한 줄을 사용합니다. 다른 벽은 닫힌 형태이며 물리적으로 반사합니다.

유효한 드래그가 구역 안에서 우측 상단 출구를 통과할 때만 기존 비행→경기 진입을 시작합니다. 단순 상/하/좌/우와 다른 모서리로 벽을 넘거나, 바깥에서 출구까지 우회하는 동작은 발사되지 않습니다. 손을 놓기 전 첫 유효 통과 이벤트로 한 번 발사하며, 느린 드래그도 허용합니다. 바깥 출구 클릭은 발사하지 않고, 안으로 들어온 뒤 다시 통과해야 합니다.

## 공유 기하와 물리

S=min(화면 너비−32px, 화면 높이−48px). 기존 내측 여백0.14S와 모서리0.10S를 유지하며, 우측 상단 레일의 위쪽 끝·오른쪽 끝을 각각 모서리에서0.18S 떨어뜨립니다. 두 끝 사이 대각선 출구 폭은 약0.255S입니다. 그림·입력·충돌이 같은 두 끝 좌표를 사용합니다.

입력 이벤트의 이전/현재 선분과 출구의 대각선 입구선 교차점을 계산합니다. 직전 위치가 구역 내부이고, 내부에서 외부 방향으로 입구선을 넘으며, 교차점이 두 벽 끝 사이에 있어야 발사됩니다. 단순히 ‘현재 위치가 우측 상단’인지만 확인하지 않으므로 다른 벽을 넘은 뒤 돌아오는 우회를 차단합니다. 실제 공에 영향을 준 드래그만 인정하고 시간 역전·중복 입력·취소 정책을 유지합니다. 출구 방향은 우측 상단45도이며, 개별 공의 실제 속도/위치와 기존 퍼짐·경기 맵 연결은 유지합니다.

공이 빠져나갈 수 있도록 우측 상단 충돌 경계를 실제로 열었습니다. 벽 끝에서는 공 반지름에 맞춰 반사하고, 나머지 둥근 벽의 반발0.52·접선 마찰0.97을 유지합니다. 출구로 나온 시각적 공이 발사 없이 남으면 바깥 화면 안전 경계에서 튕기며 기존 약한 중앙 복귀 힘으로 돌아옵니다. 위치·속도를 초기화하지 않습니다. 개별 ID·공간 해시·표시/충돌 반지름·거리별 입력 힘은 유지합니다.

기준 `519acb8`의 경기 물리·맵·룰·시드/RNG·실제 출발 슬롯·완주 순위·도착 시간·결과 화면·비행 코드·입력 어댑터·main.js는 변경하지 않았습니다. 새 대포 에셋이나 외부 의존성은 없습니다. 기존 줌 아웃·꼬리 제거·막힘 방지 알림 제거도 유지합니다. 변경된 JS 캐시 버전을 갱신했습니다.

## 자동 검사

먼저 다른 가장자리에서 발사되는 기존 동작과 닫힌 우측 상단 충돌을 실패 검사로 재현했습니다. [수정 전 로그](evidence/ne-baseline.txt). 수정 후 전체 `node --test tests/*.test.cjs` **139개 통과, 실패0개**, 약34.8초. [최종 로그](evidence/ne-all-tests.txt).

검사에는 닫힌6방향 차단, 바깥 우회 차단, 출구 경계선 접촉/짧은 통과, 실제 개별 접촉6·50·200·500개 ×프레임 묶음0/1/4의 동일 통과, 중복/시간 역전/취소, 출구 끝 반사, 화면 안전 경계, 방출 후 상태 연속과 중앙 복귀, 세 크기의 물리 스트레스·ID·겹침, 일반/모션 감소·시드 완주 재현이 포함됩니다. 과거 ‘어느 벽으로든 진입’ 기대 검사는 새 출구 정책으로 갱신했습니다.

## 직접 브라우저
