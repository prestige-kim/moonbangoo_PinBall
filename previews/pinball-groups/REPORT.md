## 디자인과 그룹 기준

사용자 참고 이미지의 좌상단 공을 기준으로 부드러운 은색 반사와 넓은 하이라이트를 가진 금속 공을 생성했습니다. 기존 사진의 검은 카메라 반사 모양을 없앴습니다. 최종 [에셋](../../assets/pinball-metal-soft.png)은1254×1254 RGBA, 투명 배경입니다. 이는 참고 기반 생성 에셋이며 실제 제품을 촬영한 사진이라고 주장하지 않습니다. 내장 imagegen 사용, [최종 프롬프트](IMAGE_PROMPT.md).2048을 요청했지만 반환 해상도는1254입니다.

공 본체는 모든 그룹·모든 단계에서 동일합니다. 공 표면 안쪽에 얇은 에나멜 색상 링을 합성하고 이름표 아래 같은 색의 선을 표시합니다. 순위/결과의 기존 참가자 표시 색상도 같은 그룹 색상을 사용합니다.

| 예시 그룹 | 공 수 | 식별 색 | 링 패턴 |
| --- | ---: | --- | --- |
| 명성 | 2 | 파랑 | 연속 원 |
| 지연 | 3 | 주황 | 2개 구간 |
| 중빈 | 4 | 초록 | 3개 구간 |

그룹은 전체 이름 문자열을 기준으로 묶습니다. 개별 `colorIndex`, 공 ID, 현재 순위, 셔플 위치에 따라 같은 그룹의 표시가 달라지지 않습니다. 세팅에 입력된 이름의 첫 등장 순서로 색상/패턴을 배정합니다. 따라서 참가자 입력 순서를 바꾸면 색상도 바뀔 수 있지만, 같은 세팅의 대기→붓기→셔플→비행→경기→완주/우승에서는 유지됩니다. 테마/모션 감소도 그룹 색을 변경하지 않습니다.

색상 외에도 링의 끊김 패턴과 실제 이름을 함께 사용합니다. 그룹이 매우 많거나500개 공이 작은 화면에 모이면 패턴/이름을 모두 읽기 어렵고 색상만으로 모든 그룹을 확실히 구분할 수는 없습니다. 기존 이름표 혼잡 방지 제한은 유지합니다.

## 구현 범위와 성능 구조

`P.Pinball`의 공통 금속 스프라이트와 동일 그룹 링 그리기를 경기/시네마 양쪽에서 공유합니다. 식별 링은 실제 반지름의0.85 위치에 그리며 가장 바깥 스트로크도 실제 반지름 안에 있습니다. 충돌 반지름을 키우지 않습니다. 유리관 원근 변형은 본체와 링에 같이 적용합니다.

사진/생성 에셋 캐시는64/128/256/512/1024 최대5단계로 유지합니다. 그룹별500개 이미지를 생성하지 않습니다. 그룹 표시는 별도 캔버스 원호로 합성하고 이름별 메타데이터만 저장합니다. 경기 엔진·규칙·시드·실제 셔플 출발 위치·순위·도착 시간 계산은 수정하지 않았습니다.
