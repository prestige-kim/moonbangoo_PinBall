This source is a real polished 60mm steel sphere, not a photograph verified as a standard 27mm pinball. It supplies the photographic chrome surface for the game pinball appearance; the game's physical radii, masses and rules are unchanged.

Game asset dimensions measured from PNG: **1254 × 1254 RGBA**, with real transparent alpha. The renderer crops the center opaque spans and clips the display to its physical circular radius, then caches 64/128/256/512/1024 sprites from the same source. No texture is recolored by participant or game phase.
