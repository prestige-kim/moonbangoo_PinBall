# TV 영상의 종이 알갱이·배경 띠 확인 — 검증 기록

사용자가 제공한 IMG_5404.MOV(29.445초, 1920×1080, 약29.97fps)의 약18~29초에서 알갱이가 있는 영역과 매끈한 영역이 수평 경계로 번갈아 나타나는 모습을 확인했다. 원본 영상과 사람의 손이 포함된 추출 프레임은 저장소에 복사하지 않았다. 이번 검토는 우측 출발 쏠림과 별도로 배경만 다룬다.

## 렌더링에서 확인·수정한 경로

- 기존 Renderer.noise는 픽셀 단위 고대비 알갱이/미세 선을 맵 타일, 바깥 배경, 고품질 화면 오버레이에 반복했다. 확대된 맵 좌표에서 스크롤되는 질감과 고정 화면 질감이 섞여 있었고 CSS feTurbulence 노이즈도 중첩됐다. TV 확대/촬영에서는 이 미세 패턴의 샘플링이 더 거칠게 보일 수 있다.
- 기존 drawBoard의 재질 그라데이션은 현재 visible.top~bottom 직사각형에만 칠했다. 실제 픽셀 비교에서 직사각형 안/밖 색이 달랐고, 이전 캡처의 배경 경계도 확인했다. 맵 전체에 같은 그라데이션을 칠하도록 바꿨다. Canvas의 클리핑이 화면 밖 픽셀을 처리하며 맵 크기/충돌은 그대로다.
- js/renderer.js: 맵 타일의 미세 노이즈를 제거한다. 로고·물결·금속/공 질감은 유지한다. 종이 질감은32px 구간을 부드럽게 보간한 결정적 패턴으로 한 번 생성해 화면 좌표에 고정한다. 패턴을 캐시하고 품질 high/low 전환에서도 같은 표면을 유지한다. 경기 RNG는 사용하지 않는다.
- style.css: screen-vignette:after의 SVG feTurbulence를 제거했다. 비네트 자체는 유지한다.
- index.html: 변경 파일의 캐시 버전을 갱신했다.

## 기본 검증과 전후 근거

`node --test qa/tv-background.test.cjs tests/visual-renderer.test.cjs qa/audio-muted.test.cjs`: 7개 통과. 캐시 적용 후 종이 검사2개도 재확인했다. 기존 경기/우측 쏠림 수정에는 이번 변경을 적용하지 않았다.

`node qa/tv-background/browser.cjs`: 이전 공개 커밋2a5e3a3과 현재 소스를 Chrome에서 동일한 카메라 위치520/1040/1560/2080, 줌1.05, CSS960×540/DPR2로 렌더링했다. 결과는 results/browser.json, 캡처는 before-*.png와 after-*.png.

- 기존 맵 타일의 장식 없는 구간에서 노이즈 최대 알파18 → 수정 후0.
- 종이 패턴의 이웃 픽셀 최대 알파 변화17 →1. 반복 경계도 매끄럽게 이어진다.
- 가시 구간 경계190/210/490/510의 실제 RGB: 기존 [251,247,239]/[251,246,238]로 달랐으나 수정 후 모두 [251,246,238]이다.
- 화면 좌표의 종이 재질은 카메라 이동 및 high→low에서 동일한 픽셀을 유지한다.
- 콘솔/요청 오류0.

`node qa/tv-background/smoke.cjs`: 기본6공 합성 터치 완주, 직전 재현의 순서·시간 일치, 요청/페이지 오류0. results/smoke.json. 이 기본 경기는 최초 질감 수정 뒤 확인했으며, 이후 재질 채움 경계와 패턴 캐시 보완은 위의 전후 네 위치 픽셀 검사로 확인했다. 전체 QA나 대량 경기를 반복하지 않았다.

영상의 실제 TV/크롬/GPU/OS 배율을 읽을 수 없으므로 해당 장비에서 최종 재확인은 필요하다. 렌더링에서 확인된 경로를 수정했고 TV 장비의 모든 원인을 확정한 것은 아니다. 이번 배경 수정은 경기 물리·장애물·출발/재현 계산에 추가 변경을 하지 않는다. 앞선 상단 출발 v2 수정은 그대로 보존했다. 배포 후에는 공개 파일과 기본 동작을 별도로 확인한다.
