# 표본 수 결정 — holdout 접근 전

사전 등록된 pilot 4경로×20판=80판: 4 worker 실제 6.888초. 전체 기본 표본 40,000판 예상 57.40분으로 사전 45분 한도를 넘었다. 따라서 허용된 대로 baseline과 최종 holdout을 **각 경로 N=5,000**으로 낮춘다(한 세트 20,000판, 예상28.70분). 당시 npm QA가 동시 실행된 로컬 CPU 조건이며 추정은 완료 시간을 보장하지 않는다. 후보3000·스크리닝3000·시간 모서리100 표본은 유지한다.

판정 기준 p≥0.01와 최대편차≤1.5pp는 그대로다. N=5,000에서 6명 ID 기대율의 Wilson95% 반폭은 약1.03pp, 3색 그룹 약1.31pp이며 각 관측의 실제 구간도 모두 보고한다. 정확히 같은 프로그램/4 worker로 측정했다. 파일럿 시드는 dev-pilot-*이고 holdout은 읽거나 실행하지 않았다.
