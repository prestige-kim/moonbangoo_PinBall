# 어른뭉방구 · 구슬 추첨

어른뭉방구 카드팩의 크림색 종이, 금박 로고, 조개·햇살 문양을 담은 오프라인 핀볼 추첨 게임입니다. 카드팩 앱에서 분리한 독립 핀볼 프로젝트입니다.

## 실행

**온라인 실행:** [어른뭉방구 핀볼](https://prestige-kim.github.io/moonbangoo_PinBall/)

GitHub Pages는 `main` 브랜치의 루트(`/`)를 배포합니다. `main`에 푸시하면 자동으로 갱신되며, `.nojekyll`로 HTML·CSS·JavaScript를 그대로 제공합니다.

이 폴더의 **`index.html`을 더블클릭**해 Chrome, Edge 또는 Safari에서 여세요. 설치, 빌드, 인터넷 연결, 개발 서버가 필요하지 않습니다. 폴더를 전달할 때는 `style.css`, `js/`, `assets/`를 함께 복사해 주세요. 외부 폰트·이미지·라이브러리·API를 사용하지 않으며 로컬 브랜드 SVG를 포함합니다. 소리는 Web Audio로 생성합니다.

모바일에서 로컬 HTML 열기를 지원하지 않는 파일 뷰어는 실행할 수 없습니다. 이 경우 폴더를 정적 서버에 올려 브라우저로 여세요. iOS Safari와 Android Chrome의 실제 기기 검증은 별도 필요합니다.

## 사용

1. 중앙 로고와 움직이는 핀볼 목업이 보이는 대기 화면에서 **시작하기**를 누릅니다.
2. 이름을 쉼표 또는 줄바꿈으로 입력합니다. `수박*2,키위*2,귤*2`는 6개 구슬입니다. 같은 이름을 여러 번 쓰려면 `이름*N`을 사용하세요.
3. 1등, 꼴등, N번째, 상위 N명 중 당첨 방식을 선택합니다. N은 구슬 수 이내의 양의 정수입니다.
4. 코스와 재질을 골라 **구슬 굴리기**를 누릅니다. 설정 패널이 접히고 게임판으로 약 1초 동안 확대됩니다.
5. 3초 카운트다운 후 모든 구슬이 도착하면 당첨자·최종 순위·시드를 확인합니다.
6. **같은 멤버로 재시작**은 같은 시드와 물리 설정으로 다시 실행합니다. **다시 설정하기**는 편집 가능한 준비 화면으로 돌아갑니다.

대기 화면은 새로 열거나 새로고침할 때 나타납니다. 배경 목업은 별도 구슬과 고정 시드로 반복되며 참가자·설정·실제 추첨 결과를 바꾸지 않습니다. 대기 중 소리는 재생하지 않고, 화면 효과 줄이기가 켜져 있으면 목업 움직임도 멈춥니다.

휠 또는 두 손가락 핀치로 확대하고 드래그로 둘러볼 수 있습니다. **F** 또는 선두 따라가기 버튼으로 자동 추적을 전환합니다. 모바일 설정 패널은 하단 시트로 열립니다. 탭이 백그라운드로 이동하면 시뮬레이션은 잠시 멈춥니다.

## 분위기와 코스

| 테마 | 스타일 | 입자와 소리 |
| --- | --- | --- |
| 문방구 종이 | 크림색 종이, 갈색 잉크, 눌러 찍은 금박 | 따뜻한 반짝임과 부드러운 종소리 |
| 홀로그램 | 아이보리, 연한 진주빛과 파스텔 포일 | 작은 색종이와 밝은 종소리 |
| 금박 | 짙은 브라운, 두꺼운 금박과 황동 | 금박 가루와 낮은 울림 |
| 은박 | 밝은 펄그레이, 은색 포일과 연한 청회색 | 은빛 반짝임과 맑은 종소리 |

코스는 테마와 독립적입니다. **자개 핀 보드**는 핀과 범퍼, **금박 회전길**은 회전 프로펠러·왕복 바·다각형, **행운 갈림길**은 깔때기·부스트·포털을 조합합니다. 테마는 경기 중에도 바꿀 수 있습니다. 시작 후에도 설정 버튼으로 패널을 열 수 있습니다.

## 경기 길이와 시작 화면

세 코스 모두 높이 **7,160**, 결승 위치 **6,960**입니다(기존 3,260 / 3,060). 기존 장애물 구간을 세 구간으로 이어 코스의 길이와 충돌 기회를 늘렸습니다. 기본 중력은 900에서 **620**으로 낮췄고, 하강 속도 540부터 공기저항을 적용해 기본 설정에서 약 659px/s로 수렴합니다. 수평 충돌의 움직임은 유지합니다.

측정용 시드의 2~200개 경기에서는 마지막 구슬이 약 32~49초에 도착했습니다. 인원·시드·맵·물리 설정에 따라 달라지고, 접전 슬로 모션과 3초 카운트다운은 추가 시간을 사용합니다. 이전 버전의 저장 설정을 처음 불러올 때 참가자와 선택은 보존하고 중력·재생 속도는 새 기본값을 적용합니다.

시작 시 설정 패널을 접고 카메라를 약 1초 동안 확대해 구슬의 출발을 보여줍니다. 모바일에서도 확대가 적용됩니다. **다시 설정하기**나 **초기화**를 누르면 준비 구도로 돌아갑니다.

## 세부 설정

- 구슬 크기 8~16, 중력 350~1500(기본 620), 반발력 0.35~0.92: 모든 구슬에 동일하게 적용됩니다. 진행 중에는 변경할 수 없습니다.
- 게임 속도 0.5~3배: 물리 스텝을 소비하는 속도를 바꿉니다. 결승 접전에서는 잠시 슬로 모션이 적용됩니다.
- 비주얼 품질 최고 / 보통 / 절약: 해상도·트레일·입자량을 조절합니다. 경기 중 FPS가 지속적으로 45 미만이면 한 단계씩 낮춥니다.
- 화면 효과 줄이기: 화면 흔들림, 순간 색수차, 섬광, UI 반복 애니메이션을 줄이고 시작 확대 시간을 짧게 합니다. OS의 모션 감소 설정을 초기값으로 사용합니다.
- 랜덤 스킬: 동일한 확률·쿨다운 규칙으로 가속·주변 밀치기·일시적 크기 증가가 발생합니다. 켜면 실제 물리에 영향을 줍니다.
- 효과음과 볼륨: 최초 시작 버튼 클릭으로 오디오를 활성화합니다. 동시 발음 수를 제한합니다.
- 시드: 비워 두면 시작할 때 생성합니다. 설정은 localStorage에 저장하고, 접근 실패 시 현재 탭의 메모리로 동작합니다.

## 재현성과 한계

물리는 1/120초 고정 스텝이며 화면 연출과 독립적입니다. **같은 시드·참가자 순서·맵·구슬 크기·중력·반발력·스킬 설정**이면 같은 실행 환경에서 도착 순서가 재현됩니다. 테마·품질·소리·게임 속도는 순위에 영향을 주지 않습니다. 부동소수점 계산 때문에 다른 브라우저 엔진 간 비트 단위 일치는 보장하지 않습니다.

같은 이름의 복수 구슬은 각각 하나의 추첨 단위입니다. 상위 N명에는 같은 이름이 두 번 당첨될 수 있습니다. 정체된 구슬에는 2.65초마다 시드 기반 임펄스를 적용하며, 강제로 순위를 지정하지 않습니다. 최대 500개를 허용하지만 성능 목표는 100~200개입니다. 모든 기기에서 60fps를 보장하지는 않습니다.

Canvas 2D로 구현하므로 WebGL 지원 여부와 무관하게 실행됩니다. 종이 질감·금박 반사·구슬 광택을 캐시해 재사용합니다. 원본 카드팩 앱의 로고와 팔레트를 참고하며 새 게임의 모든 리소스는 이 폴더에 포함됩니다.

## 구조와 확장

```text
index.html / style.css
assets/       어른뭉방구 로고 SVG
js/
  themes.js    CONFIG, 팔레트와 재질
  maps.js      코스 데이터
  physics.js   이름 파서, 시드 난수, 충돌과 결승 판정
  camera.js    추적·드래그·줌
  effects.js   입자 풀, 링과 충격 피드백
  audio.js     절차적 효과음
  renderer.js  재질 스프라이트, 종이 배경, 장애물·구슬, 미니맵
  ui.js        설정, HUD, 결과, 접근성
  main.js      게임 상태, 고정 스텝 루프, 저장, 품질 조절
tests/         물리·통합 검증
```

새 코스는 `maps.js`의 `CosmicPinball.MAPS`에 객체를 추가하고 UI의 맵 선택 버튼에 같은 `data-map` ID를 지정합니다. 맵 객체는 `id`, `name`, `subtitle`, `width`, `height`, `spawn:{x,y,width,height}`, `finish:{y}`, `obstacles`를 가집니다. 모든 장애물에는 고유 `id`를 지정하세요.

```js
{type:'pin', id:'pin-a', x:500, y:800, r:10}
{type:'bumper', id:'bumper-a', x:500, y:1200, r:38, power:110}
{type:'segment', id:'ramp-a', x1:0, y1:900, x2:200, y2:1050, thickness:7}
{type:'polygon', id:'wedge-a', points:[{x:0,y:1000},{x:220,y:1150},{x:0,y:1200}]}
{type:'rotor', id:'rotor-a', x:500, y:1600, length:240, angle:0, speed:1.2, thickness:8}
{type:'moving', id:'bar-a', x:500, y:2000, length:200, axis:'x', amplitude:120, speed:1.5, angle:0.2, thickness:8}
{type:'boost', id:'boost-a', x:500, y:2400, width:180, height:100, dx:0, dy:1, power:2100}
{type:'portal', id:'portal-a', x:300, y:1300, r:39, targetX:700, targetY:1800, exitVx:0, exitVy:380, pair:'a'}
```

포털의 도착지에는 `exit:true,pair:'a'`인 포털을 별도로 추가하면 시각적으로 연결됩니다. 새 코스의 통로를 구슬 최대 지름보다 넓게 확보하고, 도착 가능성·벽 경계를 테스트하세요.

새 테마는 `themes.js`의 `CosmicPinball.THEMES`에서 기존 테마를 복사해 새 ID와 팔레트·재질·입자 타입을 지정합니다. UI에 `data-theme-choice` 버튼을 추가하고 `audio.js`의 `SOUND_CONFIG.themes`에도 음색을 정의하세요. CSS의 테마 타일 스타일을 추가하면 선택 미리보기도 일치합니다.
